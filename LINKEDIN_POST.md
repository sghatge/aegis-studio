# LinkedIn post — draft

I’ve been building **Aegis Studio**, a personal project exploring how campaign analytics and operations can come together in one workspace.

The current prototype lets users:

• Analyse campaign performance and compare date ranges year over year
• Organise datasets, documents, checklists and actions by project
• Run basic email, URL and data-quality checks
• Export filtered reports to Excel

I built it with Python, pandas, Reflex and SQLite, using synthetic campaign data. There’s also an interactive browser demo that shows how the metrics respond to different filters.

One important distinction: the current evidence assistant uses local keyword retrieval and deterministic rules—not a generative AI model. Aegis is a learning prototype, not a production-ready CRM platform.

Explore the project and demo: https://sghatge.github.io/aegis-studio/ (demo) · https://github.com/sghatge/aegis-studio (source)

I’d welcome feedback from people working in CRM, marketing operations and analytics: **which part of campaign reporting would you most like to make easier?**
